Pipoca Sabichona Publisher

Ferramenta interna de publicação do canal infantil Pipoca Sabichona · Internal publishing tool

Utiliza os Serviços da API do YouTube · Uses YouTube API Services

Esta é uma ferramenta pessoal, de linha de comandos, usada apenas pelo dono do canal no seu próprio computador. Serve para:

  • carregar no canal os Shorts educativos criados pelo próprio dono (animação e música originais);
  • definir título, descrição, etiquetas e a marca "Conteúdo para crianças";
  • agendar a hora de publicação de cada Short;
  • atualizar a descrição e o banner do próprio canal.

A personal command-line tool used only by the channel owner, on their own computer, to upload their own original educational Shorts to their own YouTube channel, set metadata (title, description, tags, "made for kids"), schedule publication and update their own channel's description and banner. It is not offered to other users.
