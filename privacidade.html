Política de Privacidade · Privacy Policy

Última atualização: 13 de novembro de 2026 · Last updated: 13 November 2026

1. Quem somos

O "Pipoca Sabichona Publisher" é uma ferramenta pessoal usada apenas pelo dono do canal de YouTube "Pipoca Sabichona" para gerir o seu próprio canal. Utiliza os Serviços da API do YouTube.

"Pipoca Sabichona Publisher" is a personal tool used only by the owner of the "Pipoca Sabichona" YouTube channel to manage their own channel. It uses YouTube API Services.

2. Serviços da API do YouTube e Google

Esta ferramenta usa os Serviços da API do YouTube. Ao usá-la, aceitas os Termos de Utilização do YouTube. Os dados obtidos através da API do YouTube são também tratados de acordo com a Política de Privacidade da Google.

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service (https://www.youtube.com/t/terms). See also the Google Privacy Policy (http://www.google.com/policies/privacy).

3. Que dados acedemos, recolhemos e guardamos

  • Autorização OAuth da conta Google do dono do canal (token de acesso e de renovação), guardada só no computador do dono, num ficheiro local.
  • Dados do próprio canal: ID do canal, título, descrição, banner, e dos vídeos carregados pelo dono (ID, título, descrição, etiquetas, estado de privacidade e de processamento, data de publicação agendada).
  • Pesquisas públicas pontuais (search.list) para conhecer temas educativos populares; os resultados não são guardados.

Não recolhemos dados de espectadores, comentários, subscritores nem de outros utilizadores. Não usamos cookies, nem análise de tráfego, nem publicidade.

We access the channel owner's OAuth authorization (stored only on the owner's computer) and data about the owner's own channel and the videos they upload. We do not collect data about viewers, commenters, subscribers or any other users. No cookies, analytics or advertising.

4. Como usamos os dados

Apenas para carregar os vídeos do próprio dono, definir os seus metadados (incluindo a marca "Conteúdo para crianças"), agendar a sua publicação e atualizar a descrição e o banner do canal.

5. Partilha

Não partilhamos, vendemos nem transferimos dados para terceiros. Os dados só são enviados ao YouTube/Google, através da API, para executar as ações acima.

We do not share, sell or transfer any data to third parties; data is only sent to YouTube/Google through the API to perform the actions above.

6. Armazenamento e eliminação

Os tokens e os registos dos uploads (ID do vídeo e data agendada) ficam só no computador do dono. Os dados guardados da API são atualizados ou eliminados no máximo a cada 30 dias. Podes eliminar todos os dados locais apagando a pasta da ferramenta, e pedir a eliminação por e-mail para o contacto abaixo (resposta em até 7 dias).

Tokens and upload records stay only on the owner's computer. Stored API data is refreshed or deleted at least every 30 days. All local data can be deleted by removing the tool's folder; deletion requests can be sent to the contact below.

7. Revogar o acesso

Podes revogar a qualquer momento o acesso desta ferramenta à tua conta Google na página de definições de segurança da Google: https://security.google.com/settings/security/permissions.

You can revoke this tool's access to your data at any time via the Google security settings page linked above.

8. Crianças

O canal publica vídeos para crianças, marcados como "Conteúdo para crianças" conforme as regras do YouTube e a lei COPPA. A ferramenta não recolhe dados de crianças nem de quaisquer espectadores.
